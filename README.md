# Nicolás Mateos

Freelance **Shopify Plus and B2B** developer, based in Madrid and working remotely, in Spanish and English.

On Shopify since 2021, freelancing since 2022, working with brands and agencies in Spain and the rest of Europe.

## What I build

- **B2B wholesale storefronts**: companies, locations, catalogs, price lists, quantity rules and volume tiers, on Shopify B2B with Plus and without it.
- **Shopify Functions**: discounts, cart and checkout validation, payment and delivery customisations.
- **Checkout Extensibility** and customer account extensions.
- **Custom embedded apps**: Node.js, Express, Shopify CLI, Admin GraphQL integrations.
- **Core Web Vitals** on themes that were not built with them in mind.

## Code you can read

**[shopify-checkout-lab](https://github.com/NicolasShopiDev/shopify-checkout-lab)**. Real merchant tickets solved with Shopify Functions. Each one ships with its input query, its merchant settings in a metafield and its tests, and is playable at [nicolasmateos.com/#lab](https://nicolasmateos.com/#lab) running the same source file that lives in the repo.

**[shopify-b2b-order-portal](https://github.com/NicolasShopiDev/shopify-b2b-order-portal)**. A wholesale order form for Shopify B2B that does not need Plus. Access decided by one Liquid condition, catalog prices and volume breaks displayed rather than recalculated, the catalog's quantity rule driving the input, and the whole order sent in a single cart call. Built on Dawn.

**[portfolio](https://github.com/NicolasShopiDev/portfolio)**. [nicolasmateos.com](https://nicolasmateos.com) itself: Astro on Cloudflare Workers, Spanish and English from one content model, with a build that fails when a translation or a meta description is missing.
